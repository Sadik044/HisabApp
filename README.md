## About

HisabApp is a full-stack personal finance web application 
built on the 6 Jar Money Management Method. It automatically 
splits every income into 6 purposeful jars, helping users 
track expenses, build savings habits, and achieve financial 
discipline.

Supports full English and Bengali (বাংলা) language.

---

## The 6 Jar Method

| Jar | Percentage | Purpose |
|-----|-----------|---------|
| Necessities | 55% | Daily needs and bills |
| Financial Freedom | 10% | Investment and passive income |
| Education | 10% | Skills and personal growth |
| Long-term Saving | 10% | Future goals and dreams |
| Play | 10% | Fun and entertainment |
| Give | 5% | Charity and donations |

---

## Features

- Authentication — Register, Login, Forgot Password
- Income Management — Add, Edit, Delete with auto jar split
- Expense Tracking — Track expenses by jar and category
- Jar System — Individual balances, history, transfer between jars
- Dashboard — Financial overview with charts
- Reports and Analytics — Monthly reports, expense breakdown
- Export — Download PDF and Excel reports
- Dark and Light Mode — Toggle anytime
- Bilingual — Full English and Bengali support
- PWA — Install as mobile app without Play Store
- Responsive — Works on mobile, tablet, and desktop

## Tech Stack

- Frontend: React + Vite
- Styling: Tailwind CSS
- Backend: Supabase
- Database: PostgreSQL via Supabase
- Auth: Supabase Auth
- Charts: Recharts
- Language: i18next + react-i18next
- Hosting: Vercel
